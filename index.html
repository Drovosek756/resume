О моих проектах

Nosebrain Judge

Мобильное приложение для Android, предназначенное для судейства соревнований по ноузворку (nosework) в автономном режиме. Приложение включает в себя всё необходимое для организации и проведения соревнований без зависимости от интернета.


  • Создание соревнований, участников и категорий.
  • Автономное проведение соревнования и сохранение результатов.
  • Синхронизация данных с локальным веб-сервером при необходимости.
Java Android SDK (API 24+) Room (SQLite) Material Design RecyclerView

О будущем проекте

Трекер привычек

Мобильное приложение для платформы Android, помогающее пользователям вырабатывать полезные привычки (спорт, чтение, режим сна и т.д.) и поддерживать мотивацию через наглядный прогресс. Проект решает проблему нерегулярного и неудобного отслеживания привычек в обычных заметках или календарях.


Ключевой функционал:

  • Создание и удаление привычек с указанием названия.
  • Ежедневная отметка выполнения и возможность снятия отметки.
  • Автоматический подсчёт текущих серий выполнения (streak).
  • Просмотр недельной и месячной статистики выполнения.
  • Система виртуальных достижений за выполнение определённых условий (например, «7 дней подряд»).

Технические особенности и ограничения:

  • Разработка ведётся для платформы Android (версии 7.0 и выше).
  • Полная автономность: приложение работает без подключения к интернету.
  • Локальное хранение данных на устройстве пользователя.
  • Однопользовательский режим без необходимости регистрации и авторизации.
  • Интерфейс приложения выполнен на русском языке.
